# الناجي – Zombie Survivor (Godot 4.3)

لعبة تصويب وبقاء من منظور الشخص الثالث: 100 مرحلة، 10 مدن، 5 أسلحة، متجر، حفظ تلقائي. صنع في العراق.

## بناء APK عبر GitHub
1. ارفع كل الملفات إلى مستودع GitHub بنفس المسارات.
2. (اختياري) انسخ ملف الشخصية إلى `assets/characters/player.glb`.
3. Actions ← Build Android APK ← Run workflow.
4. نزّل `ZombieSurvivor-apk` من Artifacts.

APK موقّع بمفتاح debug للتجربة. للنشر على المتاجر استخدم مفتاح إصدار خاصاً بك ولا ترفعه إلى المستودع.

## خط عربي اختياري
ضع ملف خط يدعم العربية في `assets/fonts/arabic.ttf` وسيُستخدم تلقائياً.

## الخصوصية
انظر `PRIVACY_POLICY.md` (ونسخة الويب في `docs/privacy-policy.html` لاستضافتها على GitHub Pages).
